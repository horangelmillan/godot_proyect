# Pautas de Desarrollo - Proyecto GODOT

## Enfoque Educativo por Fases

Este proyecto usa un modelo de aprendizaje estructurado por fases, inspirado en el enfoque paso-a-paso de ChatGPT. Cada tarea de desarrollo se divide en fases claramente identificadas.

### Estructura de Fases para Cada Tarea

1. **FASE 1: Análisis y Comprensión**
   - Explicar QUÉ se va a hacer
   - Mostrar el estatus actual del código relevante
   - Identificar dependencias y cambios necesarios
   - Preguntar dudas antes de proceder

2. **FASE 2: Plan y Desglose**
   - Describir el plan paso-a-paso
   - Identificar las partes del código a modificar
   - Explicar el "por qué" de cada cambio
   - Permitir feedback antes de implementar

3. **FASE 3: Implementación**
   - Ejecutar los cambios de forma incremental
   - Explicar cada modificación mientras se hace
   - Mostrar código antes/después
   - Mantener puntos de verificación intermedios

4. **FASE 4: Verificación y Aprendizaje**
   - Validar que funcione correctamente
   - Explicar qué aprendizajes se obtienen
   - Mostrar resultados visibles si es posible
   - Documentar cambios principales

5. **FASE 5: Punto de Partida para la Siguiente Tarea**
   - Resumen de qué se completó
   - Estado actual del proyecto
   - Preparación clara para la siguiente etapa
   - Sugerencias para el próximo paso

### Involucramiento del Usuario

- En cada fase, el usuario puede hacer preguntas
- Se aceptan correcciones o cambios de dirección
- Se explican conceptos de Godot 4.6.3 según sea necesario
- No se ejecutan cambios sin verificación de comprensión

### Formato de Presentación

```
## FASE [N]: [Nombre Fase]

### Explicación
[Descripción clara de qué se va a hacer]

### Código Actual
[Fragmentos relevantes del código actual]

### Plan de Acción
- Punto 1
- Punto 2
- Punto 3

### ¿Preguntas o cambios antes de proceder?
```

### Completación de Tarea

Al terminar, se establece un **PUNTO DE PARTIDA** claro:
- ✅ Qué se completó
- 📊 Estado actual
- 🎯 Próximo paso sugerido
- 🔗 Referencias a código modificado

## Proyecto: Versión IA

Sistema de diálogos adaptable controlado por IA en Godot 4.6.3. 

**Rama actual:** ia-version  
**Rama principal:** main

### Stack Técnico
- Godot Engine 4.6.3
- GDScript
- Sistema de diálogos con efectos de máquina de escribir
- Transiciones de cámara suave
- Integración IA (en desarrollo)
